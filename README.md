# 知食 · 个人饮食记录

面向中国一般成年人的本机网页初版。填写年龄、性别和日常活动水平，匹配中国 DRIs 2023 每日能量人群参考值；逐餐手填食物与本次摄入的千卡数，查看每日及历史汇总。

## 启动

需要 Node.js 20 或更新版本，无需安装依赖。在项目目录运行：

```text
node server.mjs
```

然后在浏览器打开 **http://127.0.0.1:4173**。Windows 也可双击根目录的 [start.cmd](./start.cmd)。停止时在终端按 Ctrl+C。

保持使用同一个浏览器和地址。浏览器存储按地址区分，切换为 localhost、其他端口或其他浏览器时，不会自动出现原来的数据。服务仅监听本机，不向外网或局域网公开。

## 使用

1. 在“我的个人信息”中填写周岁年龄、性别分组、日常活动水平，保存后从今天起生成参考值。无需提供身高、体重；年龄需手动更新。
2. 点击“记一笔”或某一餐旁的加号。填写日期、餐次、食物名称及本次实际吃下份量的热量（千卡 kcal）。可以先记饮食，再填写个人信息。
3. 查看已记录摄入量、当日参考值及差额。支持小数和明确的零千卡记录；空白日期显示“暂无记录”。
4. 在“食物字典”中添加和维护食物、备注及一个或多个日常份量的估算热量。
5. 通过日期选择、日期箭头、近七天入口或“历史记录”补记和修改。修改记录时也可以调整日期或餐次。

修改个人信息只影响修改当天及以后；过去日期保留当时参考值。首个参考值生效日之前的饮食只汇总摄入量。参考表未提供的组合（例如 65 岁及以上高活动）仍能记录，但不生成参考值或差额。

数据仅保存在当前浏览器的本机存储中；不需要账号，不同步至服务器。清除浏览器数据会清除记录。目前字典与饮食记录分别维护；内置带来源的预置食物，支持按克数估算；也可自行添加日常份量。预置数据更新保留个人修改和删除。没有导入、导出或自动识别。

## 依据与范围

这是人群参考值对照工具，不是按身高体重计算的个体精确处方，也不提供饮食健康评分。普通成人表不适用于孕哺等需要专门营养方案的情况。

数据来源、单位换算、各年龄分组和原始证据见 [参考依据](./docs/energy-basis.md)；预置食物的数据来源、许可和范围见 [预置食物依据](./docs/preset-foods.md)。

## 验证

```text
node --test
```

测试覆盖年龄组与缺失值、热量精确加减、记录增改删与归属移动、历史参考值、存储恢复与失败保护，以及本机 HTTP 服务。

## 文件结构

- dist/：无需构建的 HTML、样式及浏览器模块。
- dist/domain.mjs：参考值、日期、饮食及汇总规则。
- dist/storage.mjs：本机存储、数据格式校验与写入失败保护。
- server.mjs：仅提供应用文件的本机静态服务，不接收健康数据。
- tests/：Node.js 内置测试，不需要第三方测试依赖。
